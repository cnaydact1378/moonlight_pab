# 달빛 팹 관리실 v0.2

Streamlit과 pandas로 반도체 검사 기록을 분석하는 한국어 대시보드입니다.

## 실행

Windows VS Code에서 이 프로젝트 폴더를 열고 터미널에서 실행하세요.

```powershell
python -m pip install -r requirements.txt
streamlit run 대시보드.py
```

`streamlit` 명령이 인식되지 않으면 `python -m streamlit run 대시보드.py`를 사용하세요.

## 파일 구조

```text
달빛팹/
├── 대시보드.py
├── 달빛팹_검사기록.csv   ← 사용자가 실제 검사 파일을 추가해야 합니다
├── requirements.txt
├── README.md
└── .streamlit/
    └── config.toml
```

작성 시 프로젝트 폴더에 CSV가 없어서 실제 열 이름·행 수·통계는 확인하지 못했습니다.
샘플 데이터를 실제 검사 파일로 생성하지 않았습니다.

CSV는 Python 파일 옆에서 찾습니다. 기본 파일명이 없고 CSV가 하나면 그 파일을 사용하며,
여러 개면 사이드바에서 선택합니다. UTF-8, CP949, UTF-16 인코딩을 지원합니다.
기본 구분자는 쉼표입니다. 기본 항목은 웨이퍼ID, 검사일, 라인, 챔버온도, 챔버압력,
증착두께, 세정농도, 파티클수, 판정입니다. 실제 열 이름이 다르면 화면의 'CSV 열 확인 및 연결'에서
연결할 수 있습니다. 항목이 없으면 관련 기능만 생략합니다. 판정 값은 합격/불합격을 사용합니다.

## 분석 기준

- 지표, 차트, 공정 평균, 파티클 상위 10건, 데이터 표, 다운로드는 모든 필터를 동시에 적용합니다.
- 탐정 보고는 필터와 무관하게 CSV 전체 기간·전체 데이터를 분석합니다. 공동 최다 라인은 모두 표시합니다.
- 합격률은 합격 건수를 전체 검사 건수로 나눕니다. 판정 미입력·알 수 없는 값도 전체 검사 건수에는 포함합니다.
- 파티클 슬라이더의 기본 최솟값에서는 결측값도 포함합니다. 값을 높이면 유효한 숫자만 비교합니다.
- 날짜 변환 실패는 날짜 차트에서 제외하며 다른 집계에는 남깁니다. 공정 평균은 결측값을 제외합니다.
- 0건 또는 판정 열 누락 시 합격률은 '—', 목표 상태는 '판정 불가'로 표시합니다.
- 다운로드는 현재 필터의 정리된 데이터이며 UTF-8 BOM을 포함합니다. 잘못된 숫자·날짜는 빈 값으로 내보냅니다.
- CSV는 화면 새로고침이나 필터 변경 때 다시 읽습니다. 자동 주기 갱신이나 장비 실시간 연결 기능은 없습니다.
